## 2. מה נעשה חי בעקבותיו (הוכח-חי בפורמן המחייה)

- **`web_search{"query"}`** — כלי-צוות אמיתי בלולאת-הכלים: Tavily key #1 → #2 עם cooldown-למסילה, timeout-9שנ', תוצאות נחתכות ועוברות `scrubSecrets` בשער. נבדק-חי: חיפוש אמיתי החזיר תוצאות דרך tavily#1.
- **`read_page{"url"}`** — קורא Jina: דף-ציבורי → טקסט, חיתוך-2400 תווים, שטיפה-בשער. נבדק-חי: 200+תוכן.
- **מגן-SSRF** — ה-URL מגיע מפלט-מודל (קלט-בלתי-אמין): loopback/RFC1918/link-local/metadata נדחים **לפני** כל-בקשה (נמדד: 127.0.0.1, 169.254.169.254, 192.168.x — נדחו; https ציבורי — אושר).
- **הפרומפט לא משקר** — הכלים מוכרזים למודל רק כשהמסילות באמת קיימות ב-env של הריצה; משרד-חסר-מפתחות מתנהג כמו קודמו במדויק.
- **אמת-יכולת ב-snapshot** — שדה `search` חדש: `{search, reader, searchLanes, calls, successes}` — ספירות-קריאות מדודות, לעולם לא ערכים. נצפה-חי דרך-הסוקט (:3010) ודרך-השער (:81, נתיב-ה-UI).
- **גישור-מישור-האוטונומיה** — `sovereign-stack/env.example` + `vault_env_bridge.py`: המסילות אופציונליות עם ברירת-מחדל-מעוצבת `unused` (מכונה-חסרת-כספת עולה כרגיל; מכונת-הכספת מקבלת ערכים אמיתיים). `UNKNOWN_DOTKEY_1` **לא** מגושר בכוונה.

## 4. חוקי-החיסכון (ייעול-הפעילות-הריבונית)

1. **failover-למפתח**: מסילה א' נכשלת → מסילה ב' באותה-קריאה, בלי-התעוררות-שגיאה אצל הצוות.
2. **cooldown-למסילה** (45שנ') — מסילה-מתה לא מוכה שוב ושוב; התאוששות אוטומטית.
3. **חיתוכים**: חיפוש 1600 תווים, דף 2400 — קונטקסט-מוח קטן = משרד-חי-יותר (אותו-חוק-חסכוניות של הספרים).
4. **טלמטריה-כנה**: `calls/successes` ב-snapshot — ניתן לראות בכל-רגע כמה הריבונות באמת משתמשת ברשת.
5. **סריקה=מלאי**: שלושת-הסרקנים (push-vaults, lineage-guard, שער-האבטחה) נושאים-עתה את כל צורות-האישורים שבכספת (tvly-/jina_/dot-format + הפלטפורמות מ-47b) — פער-כיסוי שנמצא ונסגר.
