Identity Verification API

המוצר הראשון למפתחים: האם חשבון Steem/Hive וכתובת EVM שייכים לאותו מפתח secp256k1. עוגן חד-פעמי על השרשרת, ecrecover, והתאמת רשות-חיה פר-שרשרת. ללא מפתח פרטי בשום שלב.

  • PROVEN מול בלוק Steem 109,389,994; גם FAILED נספרת כמדידה אמיתית
  • SDK אפס-תלות: Node 18+, Bun, Deno, דפדפן, edge
  • מיכסה 1,000 קריאות ליום UTC; רק SHA-256 של המפתח נשמר
חי וממוכסק בתוך הפריסה הריבונית; npm publish וגייטווי ציבורי = החלטות בעלים מדריך המפתחים

שעון אטומי (Foundry)

מצב-ראש של 6 רשתות הטרוגניות לשורש Merkle אחד: keyless, אפס עסקאות, אפס חתימות, קריאה-בלבד ברמת המכונה.

  • חישוב 15.9ms; אימות 5 הוכחות 6.8ms
  • הוכחה: 435B JSON / 160B raw
  • ריצה מתועדת: שורש 0896c3c6..., עדים מ-STEEM, HIVE, TRON, ETH, SOL
  • לעומת: OpenTimestamps בדקות-שעות; Chainlink דורש גז וועדת אמון

הראיה החיה - נשלף עכשיו, keyless, מהרשת עצמה

ממתין לשליפה... הנתונים נמדדים ישירות מהפרסומים הציבוריים של הרשת.

איך לאמת כל טענה ב-60 שניות - הזכות שלך, לא החסד שלנו

  1. פתח את קישור הסייר. etherscan.io ל-Ethereum, solscan.com ל-Solana, steemscan.com ל-Steem, hive.ausbit.dev ל-Hive, tronscan.org ל-TRON. אם כתוב "not found", הטענה מתה. עצור כאן.
  2. אשר שהעסקה קיימת. הסייר מציג סטטוס, מספר בלוק וחותמת זמן.
  3. השווה פרט אחד. אנחנו תמיד מצטטים בלוק או slot לצד הקבלה. אם הסייר מציג בלוק אחר, משהו לא תקין: הטענה מיושנת או שמעולם לא הייתה נכונה.
  4. מתקדמים: בדקו את ה-payload. לעוגנים שלנו יש שדה input או memo עם JSON או hex קטן שמכיל גובה ושורש-מצב. מבנה, לא ג'יבריש; ואם ציטטנו קידומת שורש, ה-payload מתחיל באותן התווים בדיוק.
סימני אזהרה מכל אחד, כולל אותנו: צילומי-מסך בלי קישורים; קבלות testnet שמוצגות כ-mainnet; תאריכים ישנים בלי "נכון ל-" וקישור; מזהים מקוצרים שלא מגיעים לשום מקום אמיתי.

למפתחים - שלוש שורות להוכחה

import { verifyIdentity } from "saos-id-verify";

const r = await verifyIdentity({
  username: "<steem-or-hive-account>",
  baseUrl: "https://<your-gateway>",   // הלקוח מסרב להמציא endpoint
  apiKey: process.env.SAOS_API_KEY,    // תצוגה אחת בלבד; נשמר רק SHA-256
});

התקנה מה-repo עד לפרסום ה-npm (החלטת בעלים מוצהרת): packages/saos-id-verify. תוצאות כנות: PROVEN עם מספר בלוק וקישור סייר, FAILED כתשובה לגיטימית, 401 fail-closed.
