# מחסן-המפתחות — חבילת-אימוץ-ענן (T24)

## מה-זה
הרישום-הקנוני של מלאי-המפתחות של הרשת: מה יש, מה נאמד-מול-מה, איפה-חתום, למה-משמש, ומה-חסר-רק-לבעלים.
**הבעיה-שנסגרת:** המערכת דרשה מפתחות בלי לבדוק שיש לה הכל — "כאילו כל מה שנעשה בעבר לא מדבר למערכת".

## חוק-האימוץ (מסילה-מאומתת-ענן; הסנדבוקס אינו-כותב-לגיט — נמדד 401)
1. העתק את `REGISTRY.json` → `Autonomy/state/keys/REGISTRY.json` (commit אחד, קריאה-חוזרת-מול-בלוב-שא).
2. עדכן את מחזור-ה-selfhood (Autonomy/.github/workflows/selfhood.yml):
   הוסף שלב "keys" שקורא את `state/keys/REGISTRY.json`, מודד את `demands`,
   ומפרסם `state/selfhood/keys.json` = { demandsChecked, unsatisfied[], ownerGaps[], measuredAt }.
   אסור למחזור לדרוש מפתח שאינו-במלאי; כל-דרישה-חדשה-בקוד עוברת-דרך המלאי.
3. הפצה: ops-intake מוסיף פריט-התמצאות "מחסן-המפתחות" ב-SPACE-MAP; GridWatch לא-נוגע.

## מה-האפליקציה כבר-עושה-עכשיו (בלי-אימוץ)
- `/api/keys-registry` — משרת את הרישום + מדידת-ריצה חיה (אסימון-סשן/קובץ-בעלים/קונפיג-מוח/פידי-ענן).
- לוח "מפתחות" במודעות-הרשת — חוק-הדרישה נראה-לבעלים שעה-אחת-עם-עדויות.
- פותר-אסימון אחיד לכל-המסילות (`src/lib/gh-pat.ts`): אין-אסימון = נפילה-סגורה כנה, לא 401-רעש;
  ריפו-ציבורי = אנונימי-raw קודם (network-self / world-broadcast תוקנו — האיבר-חי שוב נראה).
