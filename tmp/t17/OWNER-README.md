# ערוץ-המנהל (OWNER-CHANNEL) — הסמכות-העליונה של הריבונות [T17]

**מה-זה**: תיבת-ההוראות של הבעלים. כל-שורה ב-`inbox.jsonl` היא הוראת-מנהל
שנרשמה-מתוך צ'אט-המנהל במשרד-החי. המכריע הריבוני (sovereign-decider) קורא-אותה
**בכל-פעימה** (D0 — סמכות-עליונה), מאשר-קבלה-פומבית, ומנתב-לביצוע.

**חוקים**:
- `inbox.jsonl` — append-bounded (60) · נכתב-רק-על-ידי ערוץ-המנהל; **אסור-לערוך-ידנית**
- ההוראה-היא טקסט-חופשי; הריבונות מתרגמת-אותה-להכרעות-מדודות (MEASURE→DECIDE→PUBLISH→VERIFY)
- אפס-זיופים: אישור-קבלה מתפרסם-רק-אחרי-קריאה-מהגיט; כישלון = דיווח-כנה
- ביטחון-מידע: אין-שמות-חשבונות, אין-מפתחות, אין-פרטי-התחברות בשום-שורה (המנהל כותב-טקסט-בלבד)

**הכתובת**: צ'אט-מנהל → המשרד-החי (הדף-הראשי · כפתור 🎙️ בפינה) → שער מפתח-מנהל → הוראה
